# Client Slices

Client-facing/project-facing names used by the Digital Farm pilot.

A client slice is an abstraction and does not create a new enterprise Fabric.

Typical slices:

- Security
- Observability
- AI
- Quantum
- Operations
- Maintenance
- Shared Services
- Scalability
- Adaptive
- QAI Lab
- QAI Foundry
- Technology Transfer
- IP / Patent
- Technology
