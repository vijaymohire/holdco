## Evidence Discipline

Capabilities should be classified as:

- Concept
- Documented
- Reference Implementation
- Demonstrated
- Experimentally Validated
- Prototype
- Production / Operational

Planned or conceptual capabilities must not be represented as implemented capabilities.
