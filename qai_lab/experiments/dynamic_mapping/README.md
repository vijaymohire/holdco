improves execution quality or resource efficiency.

Static

Characterisation-aware

VirtualQubit-aware

Adaptive

Candidate metrics:

- fidelity
- error rate
- mapping stability
- remapping frequency
- execution time
- QPU occupancy
- retry/recovery rate
- result quality
