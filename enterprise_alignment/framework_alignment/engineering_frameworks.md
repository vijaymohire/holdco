# Overview

Engineering Frameworks define the reusable engineering methodologies used throughout the HoldCo Digital Enterprise Ecosystem.

Rather than relying on a single engineering discipline, HoldCo integrates multiple engineering frameworks into a unified Enterprise Engineering Framework capable of supporting research, product development, enterprise platforms, operational ecosystems and Hybrid Classical + Quantum AI (QAI) systems.

Each framework contributes specialized engineering knowledge while remaining aligned with the Enterprise Capability Architecture and Master Enterprise Reference Architecture (MERA).
