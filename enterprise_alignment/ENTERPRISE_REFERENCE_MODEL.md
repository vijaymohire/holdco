# Overview

The Enterprise Reference Model (ERM) provides the unified architectural blueprint for the HoldCo Digital Enterprise Ecosystem.

It establishes the relationships between enterprise strategy, organizational structures, enterprise capabilities, repositories, engineering workspaces, operational platforms, products and customer solutions.

Rather than defining implementation details, the Enterprise Reference Model provides a common architectural vocabulary that enables all enterprise components to interoperate within a coherent Digital Enterprise Engineering Framework.
