# Overview

The Legacy Assets section defines how previously developed enterprise assets are discovered, classified, aligned and integrated into the HoldCo Digital Enterprise Ecosystem.

Rather than replacing earlier work, HoldCo adopts an **evolutionary architecture** that preserves valuable intellectual property while progressively aligning it with the Master Enterprise Reference Architecture (MERA), Enterprise Federation Model (EFM) and Enterprise Operating Platform (EOP).

Legacy assets become reusable enterprise capabilities rather than isolated historical artifacts.

---

Legacy Asset Alignment establishes:

# Legacy Asset Philosophy

Legacy does not imply obsolete.

Within the HoldCo ecosystem, legacy assets are considered valuable enterprise knowledge that can be:

- Preserved
- Reused
- Modernized
- Refactored
- Extended
- Federated
- Productized

Every legacy asset is evaluated according to its enterprise value rather than its age.
