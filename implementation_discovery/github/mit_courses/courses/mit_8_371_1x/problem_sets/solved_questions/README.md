# Solved Questions

Purpose:
Capture solved questions separately from the original problem statements.

Solved questions are important evidence because they expose:

- reasoning;
- mathematical method;
- algorithm;
- assumptions;
- intermediate steps;
- computational procedure;
- implementation clues.

Evidence chain:

Problem
  ->
Solved Question
  ->
Reasoning
  ->
Algorithm
  ->
Pattern
  ->
Primitive Candidate
