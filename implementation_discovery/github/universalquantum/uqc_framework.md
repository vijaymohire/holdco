## 14. Relativistic Component

The notebook calculates a Lorentz gamma factor using:

    gamma = 1 / sqrt(1 - beta^2)

where beta represents the satellite velocity fraction of c.

The effective decoherence rate is then calculated using the simplified
relationship:

    Gamma_eff = Gamma_base / gamma

This is part of the demonstration model.

It should be classified as:

    Demonstration / Simplified PoC Model

and not automatically interpreted as a validated physical model.
