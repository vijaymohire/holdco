# Quantum Academics

Purpose:
Extract academic and educational assets relevant to the HoldCo knowledge
foundation.

The historical quantum repository contains a dedicated:

    Academics/

directory.

The repository's `Academics/readme.txt` states:

    "All files related to syllabus, courses and any information"

Therefore this directory should be classified primarily as:

    ACADEMIC REFERENCE
    +
    CURRICULUM REFERENCE
    +
    EDUCATIONAL KNOWLEDGE FOUNDATION

It should not automatically be classified as:

    HoldCo Curriculum
    HoldCo Course
    HoldCo Certification
    Implementation Asset
    Production Engineering Asset

unless separately created or adopted by HoldCo.

Repository evidence also shows that the parent `quantum` repository contains
material accumulated through partner courses, academic training and self-study,
and identifies its purpose as educational and demonstrational. Therefore
academic material must retain source and copyright provenance.

    IMPLEMENTATION
